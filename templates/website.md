# One-page website

Sections, top to bottom:
1. Game name, hook, and the home base button ("Wishlist on Steam" or the store's own wording).
2. Trailer.
3. Three short feature blocks, each with a screenshot.
4. Platforms and release window as currently known.
5. Press kit link and contact email.
6. Optional email sign-up. In the US, commercial emails to that list need your postal address and an easy opt-out.
Keep it fast on phones. No pop-ups.
